# Landscape-Design-Project-Management

## Secure configuration

Copy `.env.example` to `.env`, then set a dedicated database user and a long random `JWT_SECRET` before starting the backend. Do not commit `.env`.

数据库使用 MySQL5.7，前端为Vue3 + Element-Plus

# Server

### Server setup

```
npm install
```

### Compiles and hot-reloads for development

```
npm run server
